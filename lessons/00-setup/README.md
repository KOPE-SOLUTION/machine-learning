## หลักสูตรนี้เหมาะกับใคร

สำหรับผู้ที่เขียน Python และใช้ NumPy, pandas และ Matplotlib ได้แล้ว โดยเริ่มเรียน Machine Learning เป็นครั้งแรก หากต้องการทบทวน ดู [ทักษะพื้นฐานและวิดีโอในช่อง](../../docs/prerequisites.md)

บทนี้เป็นบทนำสำหรับรู้จักหลักสูตรและวิธีเรียน ส่วนแนวคิด ML และตัวอย่างข้อมูลแรกจะเริ่มใน [บท 01 — เริ่มต้น Machine Learning](../01-ml-workflow/README.md)

## เรียนแล้วจะทำอะไรได้

- ตั้งโจทย์ทำนายจากข้อมูล และเลือกข้อมูลให้ตรงกับสิ่งที่ต้องการทำนาย
- ฝึกโมเดลด้วย scikit-learn และวัดผลกับข้อมูลที่แยกไว้ทดสอบ
- ใช้ pandas และ Matplotlib ตรวจข้อมูลและอธิบายผลการทดลอง
- ทำโครงงานจำแนกภาพตัวเลข บันทึกโมเดล และโหลดกลับมาใช้ทำนาย

เส้นทางหลักคือ **01–03: เริ่มต้นและสร้างโมเดลแรก → 04–10: เตรียมข้อมูลและวัดผล → 11–14: สำรวจโครงสร้างข้อมูล → 15–17: กลไกการเรียนรู้และโครงงาน** ส่วน Mojo เป็นบทเสริมที่เลือกเรียนภายหลังได้ ดูรายละเอียดใน [สารบัญหลักสูตร](../../README.md)

## ใช้เครื่องมือเดิมต่อได้เลย

เปิด Jupyter หรือโปรแกรมเดิมที่ใช้เรียน Matplotlib และใช้ Python/kernel ที่เคยรัน NumPy กับ pandas ได้ ผู้ที่สะดวก Google Colab สามารถเรียนตามด้วย notebook ที่นั่นได้เช่นกัน

บทหลักใช้ CPU ได้ทั้งหมด ไลบรารีที่จะเพิ่มในบท 01 คือ **scikit-learn** หากรันได้อยู่แล้วใช้ต่อได้เลย ถ้าต้องติดตั้งเพิ่มเติม ดู [วิธีเริ่มเรียน](../../docs/start-here.md) หรือ [คู่มือติดตั้งสำหรับเครื่องใหม่](../../docs/setup.md)

## เรียนจาก GitHub อย่างไร

1. เปิด README ของบทที่จะเรียนเพื่ออ่านแนวคิดและดูผลลัพธ์ที่คาด
2. สร้าง notebook ของตัวเอง เช่น `ml-01.ipynb` สำหรับบท 01
3. คัดลอกโค้ด Python ไปวางใน Code cell แล้วกด **Shift+Enter**
4. อ่านผล ทดลองเปลี่ยนค่า ทำแบบฝึกหัด และบันทึกสิ่งที่สังเกตได้

README มีโค้ดครบชุด ส่วนไฟล์ `lesson.ipynb` เป็น notebook ที่เตรียมไว้ให้เลือกเปิดแทนการสร้างเอง ไม่จำเป็นต้อง clone repo เพื่อคัดลอกโค้ดมาเรียน แต่ละบทเตรียมข้อมูลและตัวแปรของตัวเองไว้ครบ
