# สร้าง notebook แล้วรันตามบทเรียน

[กลับสารบัญ](../README.md) · [บทนำ](../lessons/00-setup/README.md) · [เริ่มบท 01](../lessons/01-ml-workflow/README.md)

ใช้วิธีเดียวกับที่เรียน NumPy, pandas และ Matplotlib: **สร้างไฟล์ `.ipynb` → คัดลอกโค้ด → รัน → อ่านผล**

## 1. สร้างไฟล์ใหม่

เปิด Jupyter หรือโปรแกรมเดิมที่ใช้เรียน Matplotlib แล้วสร้าง notebook ชื่อ `ml-01.ipynb` ในโฟลเดอร์ที่สะดวก หากใช้ VS Code ให้เลือก Python ที่เคยรัน NumPy/pandas ได้อยู่แล้ว ส่วนผู้ที่สะดวก [Google Colab](https://colab.research.google.com/) สร้าง notebook ใหม่ที่นั่นได้เช่นกัน

## 2. คัดลอกโค้ดแล้วรัน

เปิด [README บท 01](../lessons/01-ml-workflow/README.md) อ่านแนวคิด แล้วคัดลอก Python block ทั้งชุดลง Code cell กด **Shift+Enter** ผลลัพธ์จะแสดงใต้ cell หากแบ่งโค้ดตาม `# %%` ให้สร้าง cell เองและรันจากบนลงล่าง โดยคัดลอก import มาครบด้วย

บทนี้ใช้ `scikit-learn` เพิ่มจากไลบรารีเดิม ถ้ารันแล้วพบ `No module named sklearn` ให้เพิ่ม Code cell ด้านบนแล้วรัน:

```python
%pip install scikit-learn==1.7.1
```

ติดตั้งเสร็จแล้ว restart kernel ของ notebook จากนั้นรันโค้ดบท 01 ใหม่ตั้งแต่ต้น คำสั่งนี้ใช้ใน notebook; ชื่อตอนติดตั้งคือ `scikit-learn` แต่ตอน import ใช้ `sklearn` หากรันผ่านอยู่แล้วให้ข้ามการติดตั้งได้

NumPy, pandas และ Matplotlib ใช้ชุดเดิมที่เคยเรียนได้ หากติดตั้งไม่ผ่านหรือยังไม่มีโปรแกรมเปิด notebook ให้ดู [คู่มือติดตั้งเพิ่มเติม](setup.md)

## 3. อ่านผลและทดลองต่อ

เมื่อเห็น `X shape: (150, 4)` และ `y shape: (150,)` ให้อ่านว่าหนึ่งแถวและแต่ละคอลัมน์หมายถึงอะไร แล้วตามต่อจนเห็น baseline ทายถูก 10 จาก 30 ดอก หรือ accuracy ประมาณ 0.333 จากนั้นทำแบบฝึกหัดท้ายบท

บันทึก `ml-01.ipynb` จากนั้นสร้าง `ml-02.ipynb` เพื่อเรียน [บท 02](../lessons/02-data-and-plots/README.md) ใช้วิธีเดิมกับทุกบท: อ่านคำอธิบาย คัดลอกโค้ด รัน เปลี่ยนค่าหนึ่งอย่าง แล้วเขียนสิ่งที่สังเกตได้

## เมื่อกลับมาเรียนต่อ

- เปิดไฟล์ `.ipynb` ที่บันทึกไว้และรัน cell จากบนลงล่าง; ตัวแปรจากครั้งก่อนอาจไม่อยู่แล้ว
- ถ้าเจอ `NameError` ให้ตรวจว่าคัดลอก import และฟังก์ชันมาครบ แล้วรันตั้งแต่ต้น
- ถ้าเห็น `In [*]` ให้รอการคำนวณจบก่อนรันซ้ำ
- โค้ดแต่ละบทสร้างข้อมูลเอง จึงไม่ต้องเปิดบทก่อนหน้าเพื่อเตรียมตัวแปร
- โดยทั่วไปไฟล์ภาพและโมเดลอยู่ใน `outputs/` ใต้โฟลเดอร์ที่ notebook ทำงาน; บท 02 บน Windows ใช้โฟลเดอร์ Projects ใต้โฟลเดอร์ผู้ใช้ และแสดงตำแหน่งเต็มหลังบันทึก ใน Colab ให้ดาวน์โหลดไฟล์ที่ต้องการเก็บก่อนจบ session ดู [Colab FAQ](https://research.google.com/colaboratory/faq.html)

ไฟล์ `lesson.ipynb` ใน GitHub เป็นตัวอย่างสำเร็จรูปสำหรับผู้ที่ต้องการเปิดดูหรือรันทั้งบท การสร้าง notebook ของตัวเองแล้วก๊อปโค้ดจาก README ให้ผลการทดลองเดียวกันเมื่อใช้ข้อมูล พารามิเตอร์ และรุ่นไลบรารีเดียวกัน
