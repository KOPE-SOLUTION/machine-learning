ใช้เป็นเอกสารอ้างอิงระหว่างเรียน ML สำหรับผู้ที่มีพื้นฐาน Python, NumPy, pandas และ Matplotlib แล้ว ส่วน array, shape และการคำนวณ NumPy เป็นทักษะเดิมที่ใช้ประกอบการอ่านสูตร ส่วนความน่าจะเป็น loss และ gradient จะอธิบายเมื่อใช้ในบทเรียน ไม่จำเป็นต้องเรียนแคลคูลัสครบก่อนเริ่ม

| สัญลักษณ์ | ความหมาย | ในโค้ด |
|---|---|---|
| n | จำนวนตัวอย่าง | len(X) |
| d | จำนวน feature | X.shape[1] |
| X ∈ R^(n×d) | ตารางตัวเลข n แถว d คอลัมน์ | array สองมิติ |
| x_i | feature ของตัวอย่างที่ i | X[i] |
| y_i | คำตอบจริง | y[i] |
| ŷ_i | คำตอบที่โมเดลทำนาย | pred[i] |
| Σ | รวมค่าตามดัชนี | np.sum(...) |
| μ, σ | ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน | mean(), std() |

## เวกเตอร์และ dot product

ถ้าตัวอย่างมี feature x=[2,3] และน้ำหนัก w=[4,5], dot product คือ 2×4 + 3×5 = 23 เพิ่ม intercept b=1 จะได้ prediction 24 ตัวเลข feature ต่างหน่วยอาจต้องปรับสเกลก่อนวิเคราะห์น้ำหนัก

```python
import numpy as np

X = np.array([[2.0, 3.0], [1.0, 4.0]])
w = np.array([4.0, 5.0])
b = 1.0
print(X @ w + b)  # [24. 25.]
```

## ระยะทางและสเกล

ระยะ Euclidean ระหว่าง x กับ z คือ sqrt(Σ_j (x_j−z_j)²) ระยะระหว่าง [0,0] กับ [3,4] เท่ากับ 5 ถ้าเปลี่ยนเมตรเป็นเซนติเมตร ระยะบนแกนนั้นจะใหญ่ขึ้น จึงมีผลต่อ KNN, SVM RBF และ K-means

Standardization ใช้ (x−μ_train)/σ_train แต่ละคอลัมน์ โดยไม่ใช้สถิติของ test หรือ validation fold

## ความน่าจะเป็นและเงื่อนไข

P(A|B) คือความน่าจะเป็นของ A เมื่อทราบ B ไม่เท่ากับ P(B|A) เสมอ ตัวอย่าง P(เป็นแมว|มีสี่ขา) ไม่เหมือน P(มีสี่ขา|เป็นแมว) Bayes' rule เชื่อมสองทิศทางด้วย prior และหลักฐาน

ความน่าจะเป็นของคลาสรวมเป็น 1 แต่ probability density ไม่ใช่ probability ของจุด ในตัวแปรต่อเนื่องต้องรวมพื้นที่ใต้ density ในช่วงที่สนใจ

## Loss และ gradient

Loss แปลงความผิดพลาดเป็นตัวเลขเพื่อให้วิธีเรียนลดค่านั้น เช่น MSE เฉลี่ยกำลังสองของ error Gradient คือทิศทางและอัตราที่ loss เพิ่มเมื่อเปลี่ยนพารามิเตอร์ การลบ gradient จึงเป็นการเดินลงในบริเวณใกล้จุดเดิม
