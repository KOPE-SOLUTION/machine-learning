# Model card: โครงงาน Digits

[กลับหน้าแรก](../README.md) · [บท 16](../lessons/16-digits-project/README.md)

## วัตถุประสงค์

สาธิต workflow จำแนกตัวเลข 0–9 จากชุดข้อมูล digits ของ scikit-learn สำหรับการเรียนรู้ ใช้ StandardScaler + SVC และเลือก C/gamma ด้วย 3-fold CV บน train

## ข้อมูลและ input contract

- ภาพ grayscale 8×8 คลี่แบบ row-major เป็น 64 คอลัมน์
- ค่าของ pixel เป็น finite อยู่ช่วง 0–16
- input มี shape (n_samples,64) และมีอย่างน้อยหนึ่งแถว
- output เป็นรหัสตัวเลข 0–9 ไม่มีตัวเลือก “ไม่ทราบ” ในโมเดลนี้

## การประเมิน

แบ่ง 80/20 แบบ stratified ด้วย seed 42; เลือก hyperparameter ตาม macro F1 และเทียบกับ baseline ที่ทายคลาสพบบ่อยที่สุด ดูค่าที่วัดจริงของการรันตนเองใน outputs/16-digits-project/metrics.json พร้อม Python/scikit-learn version และ split-indices.npz

CV score ใช้เลือกโมเดล ส่วน test score ใช้รายงานครั้งสุดท้าย ภาพ error analysis ใช้ทำความเข้าใจข้อจำกัด หากใช้ภาพเหล่านี้ปรับโมเดลต่อ ต้องออกแบบการประเมินอิสระใหม่

## ข้อจำกัด

1. ไม่ได้ทดสอบกับภาพถ่าย สมุดเขียนจริง ภาษาอื่น หรือภาพที่มีพื้นหลังต่างจากข้อมูลฝึก
2. วิธี split ไม่ได้กันผู้เขียนออกจากกัน จึงไม่ใช่การยืนยันประสิทธิภาพกับผู้เขียนใหม่
3. บังคับทายหนึ่งในสิบคลาส แม้ input เป็นภาพนอกขอบเขต
4. ไม่มีการประเมิน fairness รายกลุ่มหรือระบบเฝ้าติดตาม drift
5. คะแนนจากชุดข้อมูลเล็กไม่ยืนยันความพร้อมใช้งานในระบบสำคัญ

## การนำ artifact กลับมาใช้

เก็บ model.joblib คู่กับ lockfile และ metrics.json ใช้ environment รุ่นเดิม โหลดเฉพาะไฟล์ที่สร้างเองหรือเชื่อถือ ใช้ validate_pixels ก่อน predict และตรวจ preprocessing ของภาพให้เหมือนข้อมูลฝึก

## บันทึกการทดลองของผู้เรียน

เพิ่มวันที่ รุ่นข้อมูล ความเปลี่ยนแปลง metric ที่ตกลงก่อนทดลอง ผลของ baseline ผล validation/test และสิ่งที่โมเดลทำผิด ในรายงานของตนเอง ผลตรวจตัวอย่างที่มากับ repo อยู่ใน [สถานะการทดสอบ](verification.md)
