# ศัพท์ ML ไทย–อังกฤษ

[กลับหน้าแรก](../README.md)

| คำ | ความหมายในหลักสูตร |
|---|---|
| Sample / observation | ตัวอย่างหนึ่งรายการ มักเป็นหนึ่งแถว |
| Feature | ข้อมูลที่มีให้ใช้ก่อนทำนาย |
| Target / label | คำตอบที่ต้องการเรียนรู้ |
| Estimator | วัตถุที่มีขั้นตอน fit เพื่อเรียนจากข้อมูล |
| Training | การเรียนค่าของโมเดล |
| Inference / prediction | การนำโมเดลที่เรียนแล้วมาทำนาย |
| Generalization | ความสามารถกับข้อมูลใหม่ที่เกี่ยวข้องกับการใช้งาน |
| Baseline | วิธีอ้างอิงที่ง่ายสำหรับเปรียบเทียบ |
| Parameter | ค่าที่เรียนจากข้อมูล เช่น coefficient |
| Hyperparameter | การตั้งค่าวิธีเรียน เช่น k หรือ C |
| Train set | ชุดที่ใช้ fit |
| Validation set | ชุดที่ใช้ตัดสินใจเลือกวิธี/ค่า |
| Test set | ชุดประเมินสุดท้ายหลังตัดสินใจ |
| Cross-validation (CV) | สลับส่วนข้อมูลฝึกและตรวจสอบหลายรอบ |
| Fold | ส่วนของข้อมูลในการแบ่ง CV |
| Overfitting | เรียนรายละเอียดของข้อมูลฝึกที่ไม่ช่วยกับข้อมูลใหม่ |
| Underfitting | โมเดลยังจับรูปแบบสำคัญในข้อมูลไม่ได้ |
| Bias | ความคลาดเคลื่อนจากข้อจำกัดของวิธีเรียนในบริบท bias–variance |
| Variance | ความไวของคำตอบต่อชุดข้อมูลฝึกที่เปลี่ยนไป |
| Data leakage | ข้อมูลที่ไม่ควรรู้เข้ามามีอิทธิพลต่อการฝึก/เลือกโมเดล |
| Preprocessing | ขั้นเตรียมข้อมูลก่อนโมเดล |
| Imputation | การแทนค่าที่หายด้วยวิธีที่กำหนด |
| Scaling | การเปลี่ยนสเกลของ feature |
| One-hot encoding | แปลงหมวดหมู่เป็นคอลัมน์บอกการเป็นสมาชิก |
| Pipeline | ลำดับขั้นแปลงข้อมูลและโมเดลที่ fit/predict ร่วมกัน |
| Regularization | การจำกัดความซับซ้อน เช่นเพิ่มโทษขนาดน้ำหนัก |
| Loss | ตัวเลขที่วิธีเรียนพยายามลด |
| Metric | เกณฑ์วัดผลที่เลือกตามโจทย์ |
| Confusion matrix | ตารางนับคำตอบจริงเทียบคำทำนาย |
| Threshold | จุดตัดเพื่อแปลงคะแนนเป็นคำตัดสิน |
| Calibration | ความสอดคล้องของความน่าจะเป็นที่ทายกับความถี่จริง |
| Residual | ค่าจริงลบค่าทำนาย |
| Component | แกนผสม feature ใน PCA หรือส่วนผสมหนึ่งตัวใน GMM ตามบริบท |
| Embedding | ตัวแทนข้อมูลในพิกัดชุดใหม่ |
| Centroid | จุดศูนย์กลางของกลุ่ม |
| Density | ความหนาแน่น; พื้นที่ใต้กราฟในช่วงให้ probability |
| Distribution shift | การกระจายข้อมูลเปลี่ยนจากช่วงฝึก |
| Accuracy | จำนวนคำทำนายถูกหารด้วยจำนวนตัวอย่าง |
| Precision / recall | ความถูกต้องของสิ่งที่ทายว่าเป็นคลาสนั้น / ความครบถ้วนที่ตรวจพบคลาสนั้น |
| Macro F1 | เฉลี่ย F1 ของแต่ละคลาสโดยให้น้ำหนักเท่ากัน |
| Support | จำนวนตัวอย่างจริงของแต่ละคลาสในรายงาน |
| Vocabulary / bag-of-words | รายการคำที่เรียนจาก train / เวกเตอร์นับคำโดยไม่เก็บลำดับ |
| Sparse matrix | ตารางที่เก็บค่าที่ไม่เป็นศูนย์เป็นหลักเพื่อลดพื้นที่ |
| Prior / posterior | ความน่าจะเป็นก่อน / หลังเห็นหลักฐานที่นำมาคิด |
| Kernel (SVM) | ฟังก์ชันความคล้ายกันที่ใช้สร้างขอบเขตการจำแนก |
| Responsibility (GMM) | โอกาสเป็นสมาชิกแต่ละ component เมื่อทราบจุดข้อมูล |
| BIC | เกณฑ์เทียบความพอดีกับความซับซ้อนของโมเดล; ต่ำกว่าดีกว่าในการเทียบบนข้อมูลเดียวกัน |
| Lag | ค่าจากเวลาก่อนหน้าที่นำมาเป็น feature |
| Artifact | ไฟล์ผลลัพธ์ที่บันทึกเพื่อนำกลับมาใช้ เช่น Pipeline ที่ฝึกแล้ว |
| Reproducibility | การเก็บข้อมูล รุ่น ขั้นตอนและ seed ให้ทำซ้ำตรวจสอบได้ |

อ่านนิยามเพิ่มเติมจาก [scikit-learn glossary](https://scikit-learn.org/1.7/glossary.html) และ [Google ML glossary](https://developers.google.com/machine-learning/glossary)
